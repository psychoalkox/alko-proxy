PREFERENCES & SETUP

Make it yours.

All settings are stored locally in your Windows AppData ALKO-Proxy folder.

Engine setup

Run engine\SETUP_ENGINE_WINDOWS.ps1 to clone, patch and build the enhanced GTProxy fork. Requires Git, Python, CMake, Conan and MSVC. Copy the resulting executable path here.

Controls

Compatibility checklist

  1. Build native engine from source and install ALKO bridge.
  2. Verify certificate/hosts setup manually following upstream docs.
  3. Confirm 5.61 login, world change, and idle stability on a test account.
  4. Only then test scans, commands and item actions.

No guarantee of invisibility or ban avoidance. Do not use a valuable account for unverified network tests.
